# samples

Small sample files (a few seconds of video, a handful of frames) checked into
git for local development and demos, so a fresh clone can smoke-test
`inference-service` without downloading real datasets or model weights.

Nothing is bundled yet — drop small sample clips/frames here as they're
produced. Everything else under `../models`, `../videos`, and `../datasets`
is gitignored (see `../.gitignore`).
